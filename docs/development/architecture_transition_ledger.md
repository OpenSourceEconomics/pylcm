# Architecture transition ledger

The solver, result, and execution architecture is moving in vertical slices. During the
transition, compatibility adapters keep unmigrated solvers and the established
`Model.solve()` interface working. Bootstrap policies and deliberately deferred
integrations keep each slice bounded. Every item below has an explicit replacement or
retirement condition. A plan step is not complete while its corresponding transition
item remains without a current justification.

When a new adapter, bootstrap policy, or deferred integration is introduced, add it here
in the same change. Remove its row only after the retirement condition is covered by a
test through the replacement seam.
